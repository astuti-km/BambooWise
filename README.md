# BambooWise — Python Flask version

## Run
1. Open this folder in VS Code.
2. Install dependencies: `python -m pip install -r requirements.txt`
3. Start: `python app.py`
4. Open http://127.0.0.1:5000

## Store catalogue
Eight demo bamboo-style bottle listings are included. Demo pricing is ₹150 for 500 ml and ₹300 for 1 litre. Search matches product names, capacity, category, tags and descriptions. These are sample catalogue entries; replace the image URLs and product details with verified products before a real launch.

## Gemini assistant
Copy `.env.example` to `.env` and add your Gemini API key. Keep `.env` private and never commit it to GitHub.

Checkout is simulated only; no real payment or order fulfilment takes place.
